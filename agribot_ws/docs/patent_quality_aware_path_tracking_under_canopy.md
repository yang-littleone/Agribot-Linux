# 一种面向玉米冠下导航的感知质量约束路径跟踪方法及系统

## 一、发明名称

一种面向玉米冠下导航的感知质量约束路径跟踪方法及系统

## 二、摘要

本发明公开了一种面向玉米冠下导航的感知质量约束路径跟踪方法及系统，适用于农作物冠下无人运动平台在玉米行间环境中的自主导航。该方法首先获取车载激光雷达点云并提取作物行中心线，进一步根据左右作物行边界、中心线连续性和通行空间计算走廊置信度与安全裕度；随后以中心线作为参考路径，计算无人平台相对于目标路径点的横向误差和航向误差，通过误差反馈生成角速度控制量；同时依据走廊置信度和安全裕度对线速度、角速度限幅、历史路径恢复和安全停车策略进行约束。当感知质量下降但未完全失效时，系统使用历史可靠中心线进行降级跟踪；当置信度或安全裕度低于阈值时，控制无人平台减速或停车。该方法能够在冠层遮挡、点云间歇缺失和作物行检测不稳定条件下提高无人平台行间导航的连续性、安全性和鲁棒性。

## 三、权利要求书

### 权利要求1

一种面向玉米冠下导航的感知质量约束路径跟踪方法，其特征在于，包括如下步骤：

1. 获取无人运动平台前方冠下环境的传感器数据，并基于所述传感器数据提取作物行通行走廊的中心线；
2. 根据所述中心线、左右作物行边界或投影点云分布，计算用于表征路径可靠性的走廊置信度以及用于表征通行安全性的安全裕度；
3. 在所述中心线上选取位于无人运动平台前方预设距离处的目标路径点；
4. 根据无人运动平台当前位姿和所述目标路径点，计算横向误差和航向误差；
5. 基于所述横向误差和航向误差生成角速度控制量；
6. 根据所述走廊置信度和所述安全裕度对无人运动平台的线速度、角速度限幅、历史路径恢复或停车策略进行约束，生成最终运动控制指令。

### 权利要求2

根据权利要求1所述的方法，其特征在于，所述走廊置信度根据以下至少一种因素计算：中心线连续性、左右作物行点云数量、左右作物行间距合理性、中心线历史稳定性、作物行边界拟合残差、通行走廊宽度变化量。

### 权利要求3

根据权利要求1所述的方法，其特征在于，所述安全裕度根据通行走廊宽度和无人运动平台外形宽度计算，表达式为：

```text
M = (W - B) / 2
```

其中，`M` 为安全裕度，`W` 为估计通行走廊宽度，`B` 为无人运动平台宽度。

### 权利要求4

根据权利要求1所述的方法，其特征在于，所述横向误差和航向误差通过将目标路径点转换到无人运动平台车体坐标系下计算得到，表达式为：

```text
x_v =  cos(ψ)(x_t - x_r) + sin(ψ)(y_t - y_r)
y_v = -sin(ψ)(x_t - x_r) + cos(ψ)(y_t - y_r)
e_y = y_v
e_ψ = atan2(y_v, x_v)
```

其中，`(x_r, y_r, ψ)` 为无人运动平台当前位姿，`(x_t, y_t)` 为目标路径点坐标，`e_y` 为横向误差，`e_ψ` 为航向误差。

### 权利要求5

根据权利要求1所述的方法，其特征在于，所述角速度控制量由横向误差反馈项和航向误差反馈项共同确定：

```text
ω = PID_y(e_y) + PID_ψ(e_ψ)
```

其中，`PID_y(e_y)` 为横向误差控制项，`PID_ψ(e_ψ)` 为航向误差控制项。

### 权利要求6

```text
v = v_max · f_c(C) · f_m(M) · f_t(ω)
```

其中，`v` 为最终线速度，`v_max` 为最大线速度，`C` 为走廊置信度，`M` 为安全裕度，`f_c(C)` 为置信度因子，`f_m(M)` 为安全裕度因子，`f_t(ω)` 为转向速度衰减因子。

## 四、说明书

### 1. 技术领域

本发明属于农业机器人自主导航与路径跟踪控制技术领域，具体涉及一种面向玉米冠下环境的感知质量约束路径跟踪方法及系统，适用于农作物冠层遮挡条件下无人运动平台的行间导航控制。

### 2. 背景技术

在玉米等高秆作物生长中后期，冠层遮挡严重，卫星定位信号易受遮挡，视觉传感器也容易受到光照变化、叶片遮挡和纹理复杂度影响。车载激光雷达能够在一定程度上获取冠下作物行结构，但由于叶片遮挡、植株缺失、点云稀疏、行间杂散点和多行干扰等因素，作物行中心线提取结果可能出现间歇性不稳定。

现有农田导航路径跟踪方法通常直接使用检测得到的中心线作为参考路径，并采用 PID、纯跟踪或其他控制方法进行路径跟踪。然而，当中心线检测置信度下降或通行空间变窄时，传统控制器仍可能继续跟踪不可靠路径，从而造成频繁停车、路径抖动、行间偏移甚至碰撞风险。尤其在玉米冠下环境中，路径感知质量随植株密度、冠层遮挡和传感器视角变化而动态变化，单纯依赖几何中心线进行控制难以兼顾通行连续性和安全性。

因此，需要一种能够将路径感知质量与运动控制过程耦合的路径跟踪方法，使无人运动平台在感知可靠时正常跟踪，在感知质量下降时降级运行，在存在碰撞风险时安全停车。

### 3. 发明内容

#### 3.1 发明目的

本发明旨在提供一种面向玉米冠下导航的感知质量约束路径跟踪方法及系统，用于解决现有路径跟踪控制方法在冠下点云中心线不稳定、感知间歇缺失和通行安全裕度不足时易产生频繁停车或不安全跟踪的问题。

#### 3.2 技术方案

本发明采用如下技术方案：

首先，通过车载传感器获取冠下环境数据，并提取作物行通行走廊中心线。然后，根据左右作物行边界、通行走廊宽度、点云数量、中心线连续性等信息计算走廊置信度和安全裕度。随后，在中心线上选择目标路径点，根据车辆当前位姿计算横向误差和航向误差，并由误差反馈控制器生成角速度控制量。最后，根据走廊置信度和安全裕度对线速度、角速度限幅、历史路径恢复和停车策略进行约束，输出最终控制指令。

#### 3.3 有益效果

与现有技术相比，本发明具有以下有益效果：

1. 不仅利用中心线几何信息进行路径跟踪，还引入感知质量信息参与控制决策；
2. 在中心线短时不稳定时，可使用历史可靠中心线进行降级跟踪，减少不必要停车；
3. 在安全裕度不足时主动降速或停车，降低行间碰撞风险；
4. 能够提高玉米冠下无人运动平台的连续通行能力和安全性；
5. 适用于冠层遮挡、点云稀疏和作物行检测不稳定的农田环境。

## 六、具体实施方式

### 1. 系统组成

本实施例中的无人运动平台包括车体、驱动系统、车载计算单元、激光雷达、里程计和运动控制接口。系统运行于机器人操作系统环境中，主要包括中心线提取节点和路径跟踪控制节点。

中心线提取节点输出：

```text
/corn_row_center_line
/corridor_confidence
/corridor_safety_margin
```

路径跟踪控制节点订阅上述话题以及无人平台里程计：

```text
/odom
```

并输出速度控制指令：

```text
/cmd_vel
```

### 2. 中心线与感知质量计算

对激光雷达点云进行高度滤波、前向感兴趣区域滤波和地面投影，得到冠下植株点云分布。根据投影点云在横向方向的聚类结果提取左右内侧作物行，并生成通行走廊中心线。

走廊宽度 `W` 可由左右内侧作物行之间的横向距离估计得到。设无人平台宽度为 `B`，则安全裕度 `M` 为：

```text
M = (W - B) / 2
```

走廊置信度 `C` 可综合以下因素计算：

```text
C = w_1 C_p + w_2 C_w + w_3 C_s + w_4 C_h
```

其中，`C_p` 表示点云数量置信度，`C_w` 表示行距合理性置信度，`C_s` 表示中心线连续性置信度，`C_h` 表示历史稳定性置信度，`w_i` 为权重系数。

### 3. 目标路径点选取

在中心线上查找距离无人平台当前位置最近的路径点，并沿路径方向向前搜索预设距离 `L_d`，得到目标路径点 `P_t(x_t, y_t)`。所述 `L_d` 可为固定前视距离，也可根据路径曲率和车辆速度自适应调整。

### 4. 横向误差与航向误差

设无人平台当前位姿为：

```text
P_r = (x_r, y_r, ψ)
```

目标点在车体坐标系下表示为：

```text
x_v =  cos(ψ)(x_t - x_r) + sin(ψ)(y_t - y_r)
y_v = -sin(ψ)(x_t - x_r) + cos(ψ)(y_t - y_r)
```

则横向误差为：

```text
e_y = y_v
```

航向误差为：

```text
e_ψ = atan2(y_v, x_v)
```

### 5. 角速度控制

基于横向误差和航向误差分别计算控制项：

```text
u_y = K_py e_y + K_iy ∫e_y dt + K_dy de_y/dt
u_ψ = K_pψ e_ψ + K_iψ ∫e_ψ dt + K_dψ de_ψ/dt
```

角速度控制量为：

```text
ω = sat(u_y + u_ψ, -ω_max, ω_max)
```

其中，`sat` 为限幅函数，`ω_max` 为最大角速度。

### 6. 质量感知速度调节

定义置信度因子：

```text
f_c(C) = clamp(C, f_min, 1)
```

定义安全裕度因子：

```text
f_m(M) =
0,    M < M_stop
0.3,  M_stop ≤ M < M_mid
0.6,  M_mid ≤ M < M_high
1.0,  M ≥ M_high
```

定义转向速度因子：

```text
f_t(ω) = clamp(1 - 0.5 |ω| / ω_max, 0.2, 1.0)
```

最终线速度为：

```text
v = v_max · f_c(C) · f_m(M) · f_t(ω)
```

### 7. 状态转换策略

本发明设置三种运行状态：

| 状态 | 条件 | 控制策略 |
|---|---|---|
| 正常跟踪 | `C ≥ C_low` 且 `M ≥ M_mid` | 正常跟踪中心线 |
| 降级跟踪 | `C_stop ≤ C < C_low` 或安全裕度偏低 | 使用历史可靠中心线并降速 |
| 安全停车 | `C < C_stop` 或 `M < M_stop` | 发布零速度停车 |

其中，历史可靠中心线为最近一段时间内置信度满足要求的中心线。当当前中心线置信度降低但尚未完全失效时，控制器可在限定帧数内使用历史可靠中心线进行恢复跟踪。

### 8. 实验验证方式

在仿真环境中构建玉米行冠下通行场景，分别进行普通 PID 和质量感知 PID 对照实验。实验指标包括：

```text
行驶距离
终点横向误差
全程横向 RMSE
速度为零比例
中心线可用率
平均安全裕度
平均走廊置信度
```

实验结果可用于验证本发明在保持相近横向跟踪精度的同时，降低低质量感知阶段停车比例，提高连续通行能力和安全性。

## 七、可选扩展实施例

在另一实施例中，可进一步引入路径曲率前馈项：

```text
ω = vκ + PID(e_y, e_ψ)
```

其中，`κ` 为路径曲率，`vκ` 为曲率前馈角速度。该方式可提高曲线路径跟踪响应速度。

在另一实施例中，前视距离 `L_d` 可根据路径曲率自适应调整：

```text
L_d = L_min + (L_max - L_min) exp(-k |κ|)
```

当路径曲率较大时减小前视距离，当路径接近直线时增大前视距离，从而兼顾曲线跟踪精度和直线稳定性。
