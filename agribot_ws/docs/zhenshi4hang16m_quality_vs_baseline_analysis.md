## 结论解读
- 两组均完成 5/5 次有效实验，说明普通 PID 与质量感知 PID 在该固定场景下都具备通过能力。
- 终点横向绝对误差：质量感知 PID 为 0.004 m，普通 PID 为 0.005 m；质量感知 PID 更小。
- 全程横向 RMSE：质量感知 PID 与普通 PID 均约为 0.008 m，差异很小，说明在该固定场景下两者都能保持较好的横向跟踪精度。
- 最大横向偏差：质量感知 PID 为 0.017 m，普通 PID 为 0.017 m，质量感知 PID 略低，但差异不大。
- 平均线速度：质量感知 PID 为 0.199 m/s，普通 PID 为 0.177 m/s。普通 PID 虽然不主动按置信度降速，但在中心线为空时会频繁停车，因此整体平均速度反而更低。
- 速度为零比例：质量感知 PID 为 19.191%，普通 PID 为 38.124%，配对差值 95%CI 为 [-30.228%, -7.638%]，说明质量感知 PID 的历史中心线恢复和质量约束机制显著减少了停顿时间。
- 平均角速度绝对值：质量感知 PID 为 0.407 rad/s，普通 PID 为 0.353 rad/s；质量感知 PID 在恢复跟踪时转向响应略更积极。
- 中线可用率：质量感知 PID 为 81.009%，普通 PID 为 62.017%。该指标主要由感知节点决定，控制器是否使用置信度不会直接改变检测质量，因此不应作为控制器优劣的唯一证据。

## 论文表述建议
可以将该对照实验表述为：在相同冠下仿真场景中，相比不使用感知质量信息的普通 PID，质量感知 PID 通过引入走廊置信度、安全裕度和历史中心线恢复机制，在保持相近横向跟踪误差的同时，将速度为零比例由 38.124% 降低至 19.191%，并提高了中线可用率和平均安全裕度。结果表明，所提出的感知质量约束控制策略主要优势不是显著降低厘米级横向误差，而是减少低质量感知阶段的停顿，提高连续通行能力和运行安全性。由于样本量为 5，部分跟踪误差指标的置信区间仍有重叠，后续仍需在不同初始偏航角、不同冠层密度和不同速度条件下扩展实验。
